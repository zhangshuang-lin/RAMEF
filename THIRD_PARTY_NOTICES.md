# Third-party components and data

This is a provenance checklist, not a claim that third-party rights have been cleared. No licence or permission is inferred from a paper citation or a public download.

| Component | Relationship to this repository | Release action |
|---|---|---|
| Paderborn University bearing data (PU) | Third-party input used by the original experiments; raw recordings and feature caches are not included | Obtain from the official provider and follow its terms; verify conditions for sharing derived predictions |
| MCC5-THU Motor | Third-party input used for the run-level race-localisation study; raw CSV signals and feature caches are not included | Obtain from the official provider and follow its terms; verify conditions for sharing derived predictions |
| CWRU and SQ data | Supplementary experimental datasets discussed by the paper; raw recordings are not bundled | Use their official distribution and applicable conditions if running corresponding historical scripts |
| U2-Net / nested U-shaped encoder lineage | The project adopts the architecture idea; exact external code-copy/adaptation provenance requires author confirmation | Identify any actual upstream source and required notices before assigning a licence; do not label the adopted backbone as an original architecture |
| WDCNN, ResNet, DANN, ProtoNet baselines | Named methodological baselines implemented in the project | Keep the paper's original method citations; verify any external code-copy provenance separately |
| Python and scientific-Python dependencies | Runtime dependencies; package binaries are not redistributed here | Install independently and follow the dependencies' own licences; the project licence cannot override them |
| Times New Roman | Requested font in archived scientific figure scripts; font files are not bundled | Users must supply a legally available font installation; no font redistribution is authorised |
| Referenced papers and illustrative waveform assets | Reference PDFs and the real waveform asset used in Fig. 1 are not redistributed | Obtain papers/data separately; do not add them to this repository without permission |

Author confirmation remains required for upstream repository identities, original copyright notices, any copied/adapted code, and licence compatibility. No guessed upstream URL, DOI, copyright holder, or licence text has been added.

The archived source scripts may contain historical method names and disabled experimental branches. Their inclusion preserves traceability; it does not imply that every branch belongs to the reported RAMEF configuration or that the original datasets are covered by the eventual code licence.
